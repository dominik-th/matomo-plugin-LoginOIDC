# Matomo LoginOIDC Plugin

## Deprecation Notice (2026.11.11)

⚠️ This repository is no longer actively maintained.

No further updates, bug fixes, or support should be expected.
There are active forks available, such as [RebelOIDC](https://github.com/Digitalist-Open-Cloud/Matomo-Plugin-RebelOIDC) which you should consider migrating to.

Thanks to everyone who contributed, used, or supported this project!

## Description

Login via third party authentication services.

Easily add a "Login with GitHub" button your Matomo instance. You can also setup any other service to do the authentication for you.

## Installation

Install it via Matomo Marketplace.

Alternatively put the files from this repo in <MATOMO_INSTALLATION>/plugins/LoginOIDC and activate it in the settings.
